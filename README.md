# 🧪 Basic C Language Programs

A collection of basic C programs covering formula calculations, unit conversions, geometric distance algorithms, and variable swapping.

## 📋 Program List

* **`hello.c`**: Introductory C program printing basic output.
* **`addofTwoNos.c`**: Calculates the sum of two numbers.
* **`addofFourNos.c`**: Calculates the sum of digits for a 4-digit number.
* **`hourminutesecond.c`**: Converts time in seconds into hours, minutes, and remaining seconds.
* **`CentigardetoFehrenheit.c`**: Converts temperature between Centigrade and Fahrenheit units.
* **`distance.c`**: Converts distance from mm to cm, inches, and feet.
* **`distanceformulaUsingPoints(x,y).c`**: Calculates Euclidean distance between two coordinate points $(x_1, y_1)$ and $(x_2, y_2)$.
* **`areaofcircle.c`**: Calculates the area of a circle using $\text{Area} = \pi \times R^2$.
* **`interchange.c`**: Swaps the values of two variables using a 3rd temporary variable.
* **`No3rdVariableinterchange.c`**: Swaps the values of two variables without using a 3rd variable.

## 🚀 How to Run

Compile and execute any program using GCC:

```bash
gcc areaofcircle.c -o output -lm
./output
